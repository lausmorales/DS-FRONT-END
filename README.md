# 🌱 Esperança Viva

## 📌 Sobre o projeto

O **Esperança Viva** é um site desenvolvido para uma organização social, com o objetivo de apresentar sua atuação, projetos e formas de participação da comunidade.

A aplicação foi desenvolvida com foco em **simplicidade, acessibilidade, responsividade e facilidade de navegação**, permitindo que o usuário encontre as principais informações de forma clara e organizada.

## 🎯 Objetivos

* Apresentar a organização e sua proposta social;
* Divulgar os projetos desenvolvidos;
* Facilitar o acesso às informações;
* Permitir o cadastro de pessoas interessadas em atuar como voluntárias;
* Criar uma interface simples e intuitiva;
* Garantir uma boa experiência em computadores, tablets e smartphones.

## 💻 Tecnologias utilizadas

* **HTML5** — estruturação das páginas;
* **CSS3** — estilização, layout e responsividade;
* **JavaScript** — implementação de comportamentos e interações;
* **SVG** — utilização de elementos gráficos e ícones vetoriais;
* **Git/GitHub** — versionamento e armazenamento do código-fonte.
